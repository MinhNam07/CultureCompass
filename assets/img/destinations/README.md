# Destination photographs

Sixteen photographs sourced from Wikimedia Commons on 25 October 2026.
`credits.json` records each file’s source page, creator, license, and full Commons
imageinfo metadata, including license URLs. Country/photo mapping also lives in
`globe/destination-photos.ts`.

The photographs were downloaded as Commons thumbnails, resized proportionally
to 1600 pixels wide, and JPEG-compressed for browser delivery. No scene elements
were added or removed. Applicable CC BY / CC BY-SA licenses remain in force;
credit the listed creator and license when displaying each photograph and link
to its original file page. Spain’s image is CC0. These are views of particular
places, not visual summaries of entire national cultures.
