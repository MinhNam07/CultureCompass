# Legacy (not loaded by the site)

Files retired by the October 2026 redesign. Kept for reference and for the assignment history; nothing in the live site links to them.

- `css/street.css` — the "Biển hiệu phố cổ" signboard system (Home and Vietnam pages before the redesign).
- `css/main.css` — the earlier cream + jade system (scene, phrases, saved, about).
- `js/landing.js`, `js/hub.js`, `js/country.js`, `js/street-shell.js` — scripts for those pages.
- `fonts/anton-*` — Anton display font, no longer used.
- `pages/*.html` — copies of the HTML pages as they were before the redesign. They still point at `assets/...` paths that have since changed, so they will not render correctly if opened.

The live design system is `assets/css/cc.css`, described in `DESIGN.md`.
